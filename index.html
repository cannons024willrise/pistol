How to Use Pistol

Complete Workflow

  1. Stage 1 - Teach Tokenizer Tab: Create token types ("person", "action", "location"). Add words to each type, or paste sentences and label words.
  2. Stage 1 - Tokenize Sentence Tab: Paste a sentence. Click Tokenize. The system uses your vocabulary to break it into tokens.
  3. Stage 2: Pick two tokens. Say their relationship. Click Learn. Teach the same relationship multiple times to raise confidence.
  4. Stage 3: Type a prompt. Click Generate. See which patterns fired and the generated continuation.

Stage 1: Teach Tokenizer

The tokenizer needs to learn which words are which types. Two methods:

Method 1: Manual Create a type ("person"), then add words one at a time ("Sarah", "Marcus").

Method 2: Teach by Example Paste a sentence, click "Split into words", label each word with its type, click "Learn these words".

Pro Tips

  • Build your tokenizer vocabulary first (Stage 1, Teach tab) before you tokenize sentences.
  • Teach relationships (Stage 2) multiple times to raise confidence. Example: teach "person → location = enter" from 3 different sentences.
  • If generation fails, check Stage 3's "Which patterns matched?" to see if a pattern is missing. Go back to Stage 2 and teach it.
