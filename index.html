How to Use Pistol

The Three Stages (in order)

Stage 1: Tokenize

What it does: Breaks a sentence into semantic tokens (concepts).

How to use:

  1. Paste a narrative sentence (e.g., "Sarah noticed Marcus entering the office")
  2. Click "Tokenize"
  3. You'll see tokens appear: each word/concept with a type tag
Input: "Sarah noticed Marcus entering the office" Output: Sarah (person) noticed (action) Marcus (person) entering (action) office (location)

Stage 2: Learn Patterns

What it does: Teaches the system relationships between tokens.

How to use:

  1. After tokenizing, you'll see a dropdown with your tokens in Stage 2
  2. Pick "From" token and "To" token (e.g., Marcus → office)
  3. Type what the relationship is (e.g., "enter")
  4. Optionally: check which tokens modify this relationship (catalysts). Example: if "quickly" speeds up the action, mark it.
  5. Click "Learn This"
  6. The pattern appears in the box below. Each time you teach it again, confidence increases.

Teach multiple versions of the same relationship:

Stage 1: "Sarah entered the office"
Teach: Sarah → office = "enter" (conf 0.75)

Stage 1: "Marcus walked into the hallway"
Teach: Marcus → hallway = "enter" (conf 0.68)

→ System learns: person → location = "enter" (generalized, confidence 0.72)

Stage 3: Generate Continuation

What it does: Uses your learned patterns to continue a story.

How to use:

  1. Type a story prompt (e.g., "The lawyer entered the building")
  2. Click "Generate"
  3. The system tokenizes your prompt, looks up patterns, and shows you:
    • Activated Relationships: Which patterns matched? With what confidence?
    • Generated Continuation: The next part of the story
  4. If a pattern doesn't exist, it will flag it. Go back to Stage 2 and teach it.

Complete Workflow Example

SENTENCE 1: "Sarah noticed Marcus entering the office" Stage 1 → Tokenize: [Sarah, noticed, Marcus, entering, office] Stage 2 → Teach relationships: Marcus → office: "enter" (confidence 0.75, catalyst: action) Sarah → office: "observe" (confidence 0.65, catalyst: action) SENTENCE 2: "Marcus quickly walked to the conference room" Stage 2 → Teach more: Marcus → conference_room: "walk" (confidence 0.68, catalyst: speed) Now the system learned: person → location: "enter" or "walk" (generalized from Marcus & Sarah) PROMPT: "The lawyer entered the building" Stage 3 → Generate: Matches: person → location (0.72) Output: "The lawyer stepped inside. Everyone turned to look."

Key Concepts

Token: A semantic concept (person, action, location, etc.). Not just a word.

Pattern: A learned relationship. "Marcus → office" is concrete. "person → location" is generalized.

Catalyst: A token that modifies a relationship. "If action is present, enter is more likely."

Confidence: How sure the system is (0–1). Teach it multiple times to raise confidence.

Divergence: When the same relationship has different confidences from different sources. The system tracks this and shows you where patterns branch.

Pro Tips

  • Start simple. Teach relationships for one scene, then test generation.
  • Teach the same relationship 3+ times in different ways to build generalization.
  • Look at "Source" badges on patterns—click them to see which sentences taught what.
  • If generation fails, check the "Activated Relationships" panel. If a pattern is missing, go back to Stage 2 and teach it.
  • Catalyst checkboxes help the system understand *why* a relationship applies. Use them when certain tokens change the relationship's meaning.
